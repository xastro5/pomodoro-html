# Pomodoro 计时器

一款极简风格的 Pomodoro 计时器，采用精美的七段数码管显示、天气小组件，并支持自定义专注/休息时长。

## 功能特点

- **分组预设**：Focus（专注）包含 Long（60 分钟）和 Default（40 分钟）；Break（休息）包含 Long（15 分钟）和 Short（5 分钟），时长均可自定义。
- **自定义时长**：可直接调整计时器时长（最少 1 分钟，无上限）
- **双样式时钟**：点击时钟，即可在经典七段数码管与匹配倒计时的系统字体数字之间轻巧切换，下方显示日期
- **会话追踪**：进度圆点直观展示已完成的专注会话
- **天气小组件**：自动获取位置，以彩色线条图标显示天气及当前温度；点击温度即可在 ℃ 和 ℉ 之间切换。无法获取有效数据时隐藏
- **声音提醒**：计时结束时播放提示音（叮咚、铃声、数字音效）
- **定时闹钟**：按本地时间设置一次性闹钟，支持滚轮选时、音色选择和试听、可调稍后提醒及关闭提醒
- **深色/浅色主题**：一键切换主题
- **自适应布局**：竖屏和普通桌面使用流畅的单列布局，宽而矮的窗口采用双列，极小窗口显示迷你计时器
- **保持清醒**：页面可见时防止屏幕休眠，浏览器无法启用时显示说明
- **界面锁定**：锁定界面以防止意外操作
- **会话重置**：刷新页面后所有设置重置为默认值

## 使用方法

直接在现代浏览器中打开 `index.html`，无需服务器或构建步骤。

### 计时器控制

- **开始/暂停**：点击主按钮启动或暂停计时器
- **重置**：重新开始所选时长的会话，保留自定义时长
- **锁定**：点击锁定按钮防止意外操作
- **模式选择**：四个紧凑按钮分别使用红色专注文字、绿色休息文字，每个按钮内都有对应的专注或杯子图标，点击图标也能选择预设。选中按钮带柔和底色；悬停可查看完整名称与时长，Duration 输入框显示当前会话的总时长。
- **快速调整**：使用 +/− 或输入整数分钟，保留已经过的时间。例如 40 分钟会话进行 10 分钟后，点击 + 会将剩余时间从 30 分钟改为 31 分钟。总时长必须大于已经过的时间，自定义会话显示 Custom Focus 或 Custom Break。
- **撤销**：切换预设后，可点击 Undo 恢复之前的会话及运行或暂停状态。运行中的会话保留原结束时间。撤销提示显示八秒；鼠标悬停或键盘聚焦时延长显示，执行其他计时操作会清除提示。再次点击当前选中的预设不会重置倒计时。
- **结束时间**：运行时显示预计结束时间，暂停时显示 Paused。倒计时根据实际结束时间计算，避免浏览器延迟回调导致累计误差。暂停会保留剩余时间；重置或手动切换模式会取消尚未执行的自动切换。

会话运行或暂停期间，修改预设只影响之后的会话。当前会话使用独立的时长，确保倒计时、时长输入框和进度环保持一致。直接修改时长会保留已经过的时间；Reset 则重新开始所选的完整时长。

### 时钟与倒计时外观

点击时钟本身，即可在七段数码管和系统字体数字之间切换。两种样式显示相同的本地时间，并占用相同空间，只有轻微淡入淡出，不弹出菜单或播放声音。也可用键盘聚焦时钟，再按 Enter 或空格切换。切换不影响倒计时或闹钟；刷新页面后恢复默认的七段数码管样式。

点击倒计时数字，也可独立切换这两种样式，并支持相同的键盘操作与轻微淡入淡出。两种倒计时样式保留当前文字颜色，匹配实际可见大小。切换不影响结束时间、暂停进度或闹钟；重置及开始新一轮后保留所选样式，刷新页面后恢复系统字体数字。较长的自定义时长也会在两种样式下适应可用空间。

两种时钟样式均恢复原有红色，并匹配实际可见大小；专注与休息控件保留红绿配色，选中预设的文字略加粗。计时环线条更细，大屏下限制线宽；全屏时页脚文字仍保持小巧。超宽屏横向布局下，三个计时控制按钮位于左侧时长设置下方。

### 屏幕布局

布局优先使用居中的纵向单列，包括常见的 16:9 桌面窗口。宽度和高度充足时，时钟、倒计时、文字、按钮及间距一起按比例放大，最多为常规尺寸的 1.5 倍，避免只放大计时环。仅当窗口宽度至少为 1440 CSS 像素且宽高比至少为 2:1 时，才启用适合超宽屏的横向布局，将时钟和预设放在倒计时旁边；屏幕大本身不会触发横向布局。高度不足但宽度允许时，也会切换为紧凑横向布局，简化日期及天气详情；方形窗口在控件放得下时保持纵向布局。

极窄或极矮的窗口使用迷你布局，优先保留倒计时、播放控制和闹钟入口。原有的预设按钮和时长调整移入 Settings，特别矮的窗口以细进度条代替圆环。迷你布局省略辅助时钟、天气、会话圆点和页脚；工具栏空间不足时，外观和保持清醒功能仍可在 Settings 中使用。

调整窗口不会重置计时、暂停进度或闹钟。窄窗口的设置使用紧凑面板，空间充裕时则锚定在齿轮下方，并保留再次点击齿轮关闭的功能。闹钟保存、关闭按钮固定在可滚动内容上方。设置和闹钟面板也会根据软键盘出现后的可见区域调整；小于实用最小尺寸时，允许滚动以避免裁切操作按钮。

### 定时闹钟

应用仍然只需一个独立的 `index.html` 文件，闹钟样式和生成提示音的代码均包含在其中。

- 点击顶部闹钟图标打开编辑面板。可用鼠标滚动小时、分钟滚轮，点击可见数字，或使用方向键选择 24 小时制时间，再点击橙色对勾保存。已过的时间（包括当前分钟）会安排在明天；面板会标明 Today 或 Tomorrow，以及距离响铃的时间，例如 “in 1 hr 30 min”。
- 保存后，闹钟时间直接显示在图标旁，两者合为一个紧凑按钮。点击即可编辑，悬停提示会显示完整日期和声音状态。关闭按钮会放弃未保存的修改；**Delete Alarm** 可删除闹钟。
- 闹钟有独立的 **Sound** 开关和 **Tone** 滚轮选择器（Chime、Bell、Digital），不影响番茄计时器的音色。声音开启时，选择音色会自动试听，也可点击独立的播放按钮再次试听。
- 展开 **Tone** 可调节 **Volume**（5–100%，默认 70%），试听使用所选音量。闹钟先以所选音量的 20% 开始，再用八秒逐渐升至该音量；稍后提醒再次响起时会重新渐强。关闭 Sound 会静音，同时禁用试听和音量调节。
- **Snooze** 可选 1–15 分钟，默认 5 分钟；选择 **Off** 可关闭稍后提醒。闹钟响起后会使用保存的时长。
- 点击 **Tone** 或 **Snooze** 行可展开紧凑的滚轮，当前选项高亮，边缘渐隐。可滚动、点击可见选项，或使用方向键选择；每次只展开一个滚轮，不使用系统下拉菜单。Enter 收起滚轮；Escape 先收起已展开的滚轮，再按一次会关闭编辑面板并放弃未保存的修改。也可将鼠标移到收起的行上，直接滚动切换当前值。
- 到点后会弹出提醒并重复播放提示音。点击 **Dismiss** 或按 Escape 关闭，也可选择稍后提醒。时间、音色、音量、声音和稍后提醒的修改均在保存后生效。
- 闹钟与番茄计时器独立运行。界面锁定后无法修改闹钟，但仍可关闭或延后已响起的提醒。
- 请保持页面打开、设备唤醒。浏览器暂停运行可能使提醒延迟；恢复运行后会检查到期闹钟。关闭页面会停止闹钟，刷新页面会清除闹钟。

请使用支持 HTML dialog 和 Web Audio 的新版浏览器。若声音不可用，应用会说明情况，并仍然显示屏幕提醒。

### 设置面板

点击齿轮图标打开紧凑的设置面板，再次点击、点击面板外部或按 Escape 均可关闭。齿轮保持图标样式，面板打开时轻微高亮；设置支持键盘操作，并分为时长、计时声音和常规三组：
- 自定义各模式时长（无上限限制）
- 开关声音提醒
- 选择提示音效（叮咚、铃声、数字音效），并点击播放按钮试听
- 开关保持清醒功能；仅在浏览器实际取得唤醒锁时高亮工具栏图标，失败或中断时在设置面板中说明
- 切换深色模式

## 工作原理

Pomodoro Technique 采用专注工作时段（通常 25-30 分钟）配合短休息的方式。每完成 4 个专注时段后，系统自动触发一个长休息。

```
专注时段 → 短休息 → 专注时段 → 短休息 → 专注时段 → 短休息 → 专注时段 → 长休息
```

## 浏览器兼容性
